# Evidence Precedence Contract

Calibration Remediation Cycle 3 defines semantic state from the material proposition's current governed evidence. `unknown_internal` is a fallback, not a dominant override for unrelated uncertainty.

## Precedence

1. Explicit current authoritative prohibition produces `known_no`.
2. Explicit current authoritative conditional support produces `known_conditional`.
3. Explicit current authoritative affirmative support produces `known_yes`.
4. A known rule whose applicability needs a client-owned fact produces `missing_client_fact`.
5. `unknown_internal` applies only where no decisive current authoritative answer exists for that proposition.

Historical precedent never weakens current authoritative prohibition or affirmative support. A missing optional configuration does not invalidate current capacity support when the guest count is inside every current published configuration limit; it remains an internal uncertainty only in the unresolved range between those limits.

## Preservation

Phase 7 keeps decisive `known_yes` and `known_no` semantic states when unrelated items are unresolved. Phase 8 emits authority-gap and review effects only for the unresolved proposition, rather than converting a supported or prohibited proposition into a generic confirmation request.
