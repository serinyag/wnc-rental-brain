# Phase 6.4D Historical Hybrid Retrieval

Date: August 8, 2026

## Scope Implemented

Task `6.4D` adds a deterministic hybrid retrieval layer on top of the already-governed Phase 6 historical search-unit corpus and the already-validated:

- Phase 6 historical full-text retrieval from `6.4B`
- Phase 6 historical semantic retrieval from `6.4C`

Implemented in this task:

- historical-only reciprocal-rank fusion helper
- historical-only hybrid search function
- deterministic lexical-plus-semantic candidate fusion
- historical filter parity across hybrid retrieval
- hybrid/component score diagnostics in the returned contract
- candidate-depth strategy evaluation
- hybrid benchmark tooling and report generation
- focused pgTAP coverage for hybrid behavior, metadata, safety, and readiness preconditions
- readiness audit for handoff into `6.4E`

Not implemented in this task:

- current-plus-historical retrieval fusion
- RAG
- answer generation
- context-pack assembly
- workflow or agent integration

## Objects Created

### Reciprocal-Rank Helper

Created:

- `private.historical_hybrid_rrf_score(integer, integer)`

Purpose:

- keeps Phase 6 hybrid rank fusion independently named from Phase 5 current-knowledge hybrid retrieval
- returns `0` for null or invalid ranks
- applies the approved reciprocal-rank formula `1 / (k + rank)`

### Hybrid Search Function

Created:

- `private.search_historical_case_units_hybrid(...)`

Purpose:

- fuses the Phase 6 historical FTS and Phase 6 historical semantic candidate sets
- returns only Phase 6 historical search units
- preserves historical authority and safety metadata rather than flattening precedent into current knowledge

## Determinism And Preconditions

Deterministic ordering:

1. `hybrid_score desc`
2. `best_component_rank asc`
3. `case_code`
4. `unit_type`
5. `search_unit_id`

Runtime preconditions:

- nonblank query text
- non-null query embedding
- exactly one active retrieval-approved historical embedding model unless a valid model id is supplied
- query vector dimensions must match the active historical embedding model
- historical semantic coverage must be complete for current eligible units

If current embedding coverage is incomplete or stale, hybrid retrieval fails closed rather than silently degrading.

## Safety And Isolation

Historical hybrid retrieval remains:

- `historical_precedent`

It does not imply:

- current authority
- current policy
- current legal validity

Validated behavior:

- limited precedents remain searchable and explicitly tagged as limited
- analyst-inference lessons remain searchable and explicitly tagged
- historical-value-only / high-risk rows preserve contamination and current-authority disposition metadata
- confidentiality, PI, provenance, and source locator metadata survive the fusion layer

Phase 5 isolation result:

- Phase 5 hybrid surface remains unchanged
- `private.current_knowledge_chunks` remains unchanged
- no current-knowledge fusion was introduced
