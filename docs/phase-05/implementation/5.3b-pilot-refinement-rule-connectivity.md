## Chunk-Level Rule Connectivity

### New tables

Added:

- `private.knowledge_chunk_logical_rules`
- `private.knowledge_chunk_rule_versions`

Both tables:

- enforce controlled relationship target kinds
- enforce parent-document governance scope
- are private, RLS-enabled, and direct client-role access is revoked

### Parent-document governance enforcement

Stable logical rule links are allowed only when the parent document version already links to the same `rule_code` in `public.knowledge_document_version_logical_rules`.

Exact rule-version links are allowed only when the parent document version already links to the same `rule_version_id` in `public.knowledge_document_version_rule_versions`.

This prevents chunks from becoming a hidden independent governance layer.
