## Reliability Principles Required For 8.0B

8.0B must explicitly preserve these requirements:

1. No autonomous workflow agent.
2. Generated prose is not workflow truth.
3. Missing authority becomes workflow state.
4. Decisions and communication are separate.
5. Actions exist as structured records before execution.
6. External execution cannot silently advance state.
7. Case changes are proposals before becoming truth.
8. Case-specific exceptions are scoped.
9. Approval UI is replaceable.
10. Human-in-the-loop is risk based.
