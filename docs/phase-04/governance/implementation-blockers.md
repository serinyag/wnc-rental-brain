# Implementation Blockers

This register keeps unresolved policy or source issues separate from working Phase 4 rule domains.

Governance note: a blocker belongs here only when the missing or conflicting policy prevents a domain from being implemented correctly or from making a controlled decision that the current scope requires. Items that do not block the approved slice and instead describe optional future automation or richer modeling should be recorded as deferred enhancements, not blockers.
